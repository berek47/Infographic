The important thing is not the exact numbers. It is the live pattern: each token can pull information from anywhere in the sentence in one step.

The takeaway

Attention is all-to-all: with no fixed reading order, every token can pull meaning from any other in a single step.

All-to-all

Every token can read every other token directly, not only its neighbor.

Multi-head

Different heads can learn different patterns: grammar, reference, position, or topic.

Why it matters

This is the mechanism behind context: the model can connect “it” back to “cat”.

§1The computation

Each row is a query. Each column is a key. The model scores every pair, then normalizes the row so the values sum to one.

Attention(Q,K,V) = softmax(QKᵀ / √d) · V (1)

Lower temperature makes the winning square darker; higher temperature spreads attention across more words.

§2How to read the figure

Click a word on the left or in the token row. The highlighted row shows where that word is getting context from. In the resolver head, the pronoun it attends strongly to cat.
